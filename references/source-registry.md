# Authoritative source registry

Last reviewed: 2026-09-03. These links support decisions; the target journal's current official pages remain controlling. Recheck version/date before relying on time-sensitive policy.

| Topic | Authority and URL | Use |
|---|---|---|
| General biomedical conduct, reporting, manuscript sections, submission, authorship, AI | [ICMJE Recommendations](https://www.icmje.org/recommendations/) | Current baseline for biomedical journals; updated January 2026 when last checked |
| Reporting guideline discovery | [EQUATOR Network library](https://www.equator-network.org/reporting-guidelines/) | Find the guideline and extensions matching the design |
| Randomized trials | [CONSORT](https://www.consort-spirit.org/) | Use the current trial-reporting statement; CONSORT 2025 was current when checked |
| Systematic reviews | [PRISMA](https://www.prisma-statement.org/) | PRISMA 2020 checklist, flow diagrams, and extensions |
| Observational studies | [STROBE](https://www.strobe-statement.org/) | Cohort, case-control, and cross-sectional reporting |
| Animal research | [ARRIVE](https://arriveguidelines.org/) | ARRIVE 2.0 Essential 10 and Recommended Set |
| Publication ethics | [COPE core practices](https://publicationethics.org/core-practices) | Authorship, conflicts, data, peer review, misconduct, corrections |
| Contributor roles | [CRediT](https://credit.niso.org/) | Standardized 14-role contribution statements; not authorship criteria |
| Journal trust checks | [Think. Check. Submit.](https://thinkchecksubmit.org/) | Venue due diligence and predatory-journal risk checks |
| Open-science practices | [TOP Guidelines](https://www.cos.io/initiatives/top-guidelines) | Registration, protocol, analysis plan, materials, code, data, reporting transparency |
| Data/material/code reporting example | [Nature Portfolio reporting standards](https://www.nature.com/ncomms/editorial-policies/reporting-standards) | Strong reproducibility and availability-policy reference; not universal journal policy |
| Engineering article structure and tools | [IEEE Author Center](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/) | IEEE-specific structure, templates, references, PDF/LaTeX checks, data/code |
| Reference formatting examples | [NLM Citing Medicine](https://www.ncbi.nlm.nih.gov/books/NBK7256/) | Public-domain detailed citation construction, especially biomedical/NLM style |
| Persistent identifiers | [Crossref for researchers](https://www.crossref.org/community/researchers) | DOI lookup/verification and persistent links |
| Researcher identifiers | [ORCID guidance](https://support.orcid.org/hc/en-us/articles/360006897334-What-is-an-ORCID-iD-and-how-do-I-use-it) | Name-independent researcher identity and submission workflows |
| Units and quantities | [BIPM SI Brochure](https://www.bipm.org/en/publications/si-brochure) | Current authoritative SI definitions and writing conventions |
| Academic phrase patterns | [University of Manchester Academic Phrasebank](https://www.phrasebank.manchester.ac.uk/) | Language patterns for non-native writers; adapt, do not bulk copy |
| Book identification / edition metadata | [Cambridge official 8th-edition frontmatter](https://assets.cambridge.org/97813166/40432/frontmatter/9781316640432_frontmatter.pdf) | Confirms title, authors, edition, ISBN, DOI; not a substitute for a licensed full text |
| Chicago style (current rules) | [The Chicago Manual of Style](https://www.chicagomanualofstyle.org/) and [University of Chicago Press — Turabian catalog record](https://press.uchicago.edu/ucp/books/book-details.html?isbn=9780226823379) | The bundled Turabian follows CMOS 15th (2003); check current CMOS/Turabian editions for updated rules on electronic sources and other post-2007 changes before final citation formatting |

## Freshness rule

Search official pages again for target-journal instructions, article types, fees, templates, reporting-guideline versions, AI policy, open-access terms, indexing claims, submission systems, and deadlines. Record the access date and direct URL in the requirement ledger. When sources conflict, report the conflict and follow the target journal or seek editorial clarification; do not silently choose the more convenient rule.
